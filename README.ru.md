# Minecraft Restrictions — мод для испытания

[🇷🇺 Русский](README.ru.md) | [🇬🇧 English](README.md)

**Minecraft Java 26.3 · Fabric**

Мод превращает правила ролика в реальные игровые ограничения. Как только срабатывает условие, ограничение включается **навсегда для этого игрока в этом мире**: выход из мира, перезапуск игры или смерть его не сбрасывают.

## Правила испытания

1. **Получил железный слиток** → спринт запрещён.
2. **Получил алмаз** → щит запрещён.
3. **Впервые вошёл в Незер** → броня запрещена.
4. **Обнаружил крепость Незера** → лук запрещён.
5. **Впервые вошёл в Энд** → ставить блоки запрещено.
6. Цель — победить Дракона Края.

## Визуальная часть

- Уведомления об активации каждого ограничения — на русском.
- Текущее состояние ограничений показывается в action bar.
- Броня снимается при активации соответствующего ограничения.

## Важные уточнения

- Железо и алмазы срабатывают, когда предмет оказывается в инвентаре. Не требуется именно переплавить железо или добыть алмаз конкретным инструментом.
- Крепость определяется по характерным блокам адского кирпича рядом с игроком. Это практичный триггер для записи, но он может сработать, если такие блоки были построены игроком.
- «Запрет блоков» означает запрет **ставить** блоки; ломать блоки можно.
- Состояния сохраняются в данных игрока через persistent scoreboard tags.

## Сборка

Нужны Java 25 и Gradle. В корне проекта выполни:

```bash
./gradlew build
```

В Windows:

```bat
gradlew.bat build
```

Готовый JAR появится в `build/libs/`. Для запуска установи Fabric Loader для Minecraft 26.3 и Fabric API подходящей версии.
