# Призрачный напарник — Fabric 26.3

[🇷🇺 Русский](README.ru.md) | [🇬🇧 English](README.md)

Кооперативный режим для двух игроков. После первой смерти погибший становится невидимым призраком-наблюдателем, а выживший должен найти точку смерти и провести там ритуал воскрешения за четыре минуты.

> Это ранняя сборка: исходники реализуют описанные ниже механики, но перед записью всё ещё нужен игровой тест на сервере с двумя клиентами.

## Сейчас реализовано

- Запуск раунда после смерти одного из ровно двух подключённых игроков; состояние раунда сохраняется в данных мира.
- Автоматический респаун призрака с коротким затемнением вместо долгого экрана смерти.
- Режим наблюдателя для призрака. Его настоящее тело следует вокруг выжившего по горизонтальной орбите; высота тела следует за прыжком выжившего, а голова плавно поворачивается к нему.
- Камера призрака орбитально смотрит на выжившего. Позиция камеры сглаживается с учётом времени кадра, а колёсико мыши меняет радиус орбиты; новое расстояние синхронизируется с сервером, чтобы тело оставалось рядом с камерой.
- Маленькая модель души показывается только на клиенте призрака.
- Выживший получает компас спасения. Пока он держит компас в руке, видны направление, расстояние, таймер и прогресс ритуала; ПКМ по компасу открывает отдельную панель с координатами точки смерти.
- Маяк из частиц душ, защита лута от despawn, удержание Shift для ритуала и сброс ритуала при движении или получении урона.
- Воскрешение с 6 HP и Resistance на 3 секунды.
- Проигрыш при смерти выжившего или истечении времени.
- Команды оператора `/ghostpartner status`, `/ghostpartner reset` и `/ghostpartner restart`.

## Ещё не готово / требует проверки

- Финальная модель призрака со скином и анимациями (текущая душа — временная кубическая модель).
- Отдельный зарегистрированный предмет и текстура компаса: сейчас используется ванильный компас, для которого добавлена панель.
- Проверка движения и камеры на реальном выделенном сервере, в одиночном мире и при нестабильной сети.
- Интеграция Simple Voice Chat, финальная графика и автоматические игровые тесты.
- Функция безопасного удаления мира намеренно не реализована; конфиг-параметр `deleteWorldOnFailure` зарезервирован и ничего не удаляет.

## Сборка

Нужны Java 25 и Gradle. Из корня проекта:

```bash
gradle --no-daemon clean build
```

JAR появится в `build/libs/`. Установите Fabric Loader для Minecraft 26.3 и совместимую версию Fabric API; мод должен быть установлен на сервере и обоих клиентах.

## Тест вручную

См. [`docs/TESTING.md`](docs/TESTING.md). В частности, проверьте респаун без меню, орбитальное движение на разных значениях зума, прыжок выжившего, компас и воскрешение.
