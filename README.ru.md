# Призрачный напарник — Fabric 26.3

Кооперативный хардкор-мод для двух игроков. После первой смерти раунд переходит в состояние спасения: погибший становится призраком-наблюдателем, а выживший должен провести ритуал у точки смерти за четыре минуты.

## Состояние реализации

Это ранняя сборка ядра механики, а не завершённая версия всего ТЗ.

Реализовано в исходниках:
- обнаружение первой смерти в паре из двух подключённых игроков;
- сохранение состояния раунда в данных мира;
- режим наблюдателя для погибшего игрока;
- таймер на четыре минуты, показываемый в Actionbar;
- маяк из частиц душ и попытка защитить лут от despawn;
- удержание Shift для ритуала, сброс прогресса при движении/уроне;
- воскрешение с 6 HP и Resistance на 3 секунды;
- проигрыш при смерти выжившего или истечении времени;
- команды оператора `/ghostpartner status` и `/ghostpartner reset`.

Пока не реализовано/не подтверждено:
- полупрозрачная модель призрака со скином (сейчас используется spectator);
- отдельный круговой клиентский HUD и точная стрелка-направление;
- полноценная обработка удержания ПКМ;
- конфигурационный файл;
- фильтр голоса Simple Voice Chat;
- безопасное закрытие одиночного мира и опциональное удаление сохранения;
- тестирование в запущенной игре.

## Сборка

Требуется Java 25. Из корня проекта:

```bash
gradle --no-daemon clean build
```

Готовый JAR появится в `build/libs/`.

## Установка

1. Установить Fabric Loader для Minecraft 26.3.
2. Установить совместимый Fabric API.
3. Положить собранный JAR в `mods` на сервере и на клиентах.
4. Для игры вдвоём подключить ровно двух игроков.

## Важные ограничения

- По умолчанию мод не удаляет папку мира.
- Состояние проигрыша сохраняется в данных мира; оператор может сбросить тестовый раунд командой `/ghostpartner reset`.
- Эта версия ещё требует компиляции и проверки в Minecraft. Не считай перечисленные механики протестированными до успешного CI-сборочного процесса и игрового теста.
